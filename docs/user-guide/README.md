# GovLens Guide

Illustrated, self-contained documentation. Open **`index.html`** in a browser (or serve this folder).

- **[`index.html`](index.html)**: **User Guide**: requesting access, approvals, the dashboard, the Requests hub.
- **[`operator.html`](operator.html)**: **Operator Guide**: architecture, provisioning the service principals,
  the config reference, running, going live, day-2 ops, hardening, troubleshooting.
- **`assets/guide.css`**: shared styling for both pages.
- **`screens/`**: the screenshots: real GovLens screens rendered with **neutral example data**
  (`dashboard.html`, `request.html`, `requests.html`, `admin.html`).

The two guides cross-link via the tabs in the top bar.
