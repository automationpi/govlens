Grant a role

Global grants apply tenant-wide; a subscription grant scopes the role to that subscription only — so a team's approver can only approve revocations for their own subscription, and a subscription admin can add approvers for it. Any signed-in user can view and request. Bootstrap global admins come from GOVLENS_ADMIN_EMAILS.
